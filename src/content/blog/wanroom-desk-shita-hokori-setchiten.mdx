## 先に、たぶん効かない3つ

この手の記事はふつう最後に「今回すすめなかった手」を置きますが、今回は先に書きます。デスク下の話は、<strong>買う物を間違えたときの無駄が大きい</strong>からです。

<strong>1. 極細ヘッドのスティック掃除機に買い替える。</strong>
床に触れている物の数は1個も減りません。ヘッドを細くすれば通れる隙間は増えますが、一度に吸える幅も同じだけ減るので、往復の回数が増えるだけです。ここに1万円以上を足すのは、正直もったいないと思います。

<strong>2. 床置きのケーブルボックス。</strong>
配線は隠れますが、接地点は<strong>1個増えます</strong>。しかも中にタップが入って重くなるので、掃除のたびにどかす気にはなりません。あれはテレビ台の裏のように「掃除の頻度が低くていい場所」の道具で、毎日足が入る場所には向いていないというのが編集部の見方です。

<strong>3. ロボット掃除機。</strong>
前回書いたとおりで、デスク下は高さでは引っかからないのに、脚とキャスターとケーブルで入れません。ロボットは「入れなかった場所」をアプリ上で未清掃として報告しないので、掃除できていないことにすら気づけません。

## まず数える。お金はかかりません

しゃがんで、デスクの下で<strong>床に触れている物</strong>を数えてください。ケーブルは、床に垂れて接している箇所を1本1個と数えます。

在宅ワークのワンルームでよくある構成を編集部で棚卸しすると、こうなりました。

| 床に触れている物 | 個数 |
| --- | --- |
| デスクの脚 | 4 |
| チェアのキャスター | 5 |
| 電源タップ | 1 |
| ACアダプタ（ノートPC・モニター・ルーター） | 3 |
| 延長コードのとぐろ | 1 |
| ゴミ箱 | 1 |
| <strong>合計</strong> | <strong>15</strong> |

自分の部屋の数を出したら、ここで判断が決まります。

| 数えた個数 | やること |
| --- | --- |
| 5個以下 | 椅子を転がして外に出すだけで、手持ちの掃除機が届きます。<strong>この記事の残りは読まなくて大丈夫です</strong> |
| 6〜10個 | 上げれば帯が通ります。ケーブルトレーかタップホルダーの出番 |
| 11個以上 | 上げたうえで、細いノズルで吸う道具も要ります |

床置きの物が5個以下の人は本当に読まなくていいです。時間を返します。

## 5本の帯のうち、何本が素通しか

数字を置きます。スティック掃除機の床用ヘッドは、幅20cm台のものが多いです。ここでは<strong>25cm</strong>を編集部の仮置きとして使います（自分の掃除機のヘッドを測れば、その数字に置き換えられます）。

幅120cmのデスク下を、幅25cmの帯で手前から奥へ掃くと、120 ÷ 25 ＝ <strong>4.8本</strong>。端数を入れて5本の帯で覆う計算になります。ここに15個の接地点が散っていると、1本あたり平均3個。<strong>障害物がゼロの帯は、まず1本も残りません</strong>。

「掃除機が入らない」と感じているとき、実際に起きているのはこれです。高さは足りている。通り道が1本もないだけです。

## 掃除されているのは、手前の30cmだけかもしれません

もう1つ、配置の偏りがあります。コンセントは壁にあるので、タップもACアダプタも延長コードも、<strong>ぜんぶ奥の壁側に寄ります</strong>。手前は椅子が転がるので、そもそも物を置けません。

つまり奥行き60cmのデスク下は、手前30cmは掃きやすく、奥30cmは物で埋まっている、という分かれ方をしているはずです。面積にすると 1.2 × 0.3 ＝ <strong>0.36m²</strong>。デスク下のちょうど半分が、たぶん引っ越してから一度も掃除されていません。デスクを動かしたときに奥だけ綿ぼこりが分厚い、という経験があるなら、理由はこれだと思います。

## 順番は「上げてから吸う」

やることは2手です。

<strong>1手目：床から物を上げて、接地点を15個から9個にする。</strong>
電源タップ1個、ACアダプタ3個、延長コードのとぐろ1個、ゴミ箱1個。この6個は天板裏か壁側に移せます。残るのはデスクの脚4本とチェアのキャスター5本で、脚は動かせませんが、椅子は掃除のとき転がして外に出せます。<strong>実質4個</strong>まで落ちれば、5本の帯のうち3本は素通しになります。

<strong>2手目：それでも残る脚の周りを、細いノズルで吸う。</strong>
脚の付け根は幅25cmのヘッドでは絶対に届きません。ここは隙間ノズルの仕事です。手持ちの掃除機に付属していれば、まずそれを試してください。買い足す前に、付属品の袋を探すのが先です。

この順番を逆にすると、たいてい失敗します。掃除機を先に買っても、床の15個は減らないからです。

## 「ワイヤーだからホコリが溜まりにくい」は、半分だけ本当

ワイヤータイプのトレーは「網目なのでホコリが溜まりません」と説明されます。それは正しいのですが、溜まらなかったホコリは<strong>下に落ちます</strong>。落ちる先は床です。

つまりトレーはホコリを減らす道具ではありません。<strong>ホコリが落ちる先を、掃除できる床に変える道具</strong>です。ここを取り違えると「浮かせたのに床が汚れる」と感じることになります。床が汚れるのは正常で、大事なのはそれを一往復で吸えるかどうかのほうです。

## 用途別の選び方まとめ

- **数えたら5個以下だった** → 何も買わなくていいです。椅子を出して吸えば終わります

- **浮かせたいのはタップ1個とアダプタ2〜3個だけ／机が小さい** → サンワダイレクト 200-CT010BK
- **引き出し付きの机でトレーが付かない／まず最小構成で試したい** → サンワサプライ TAP-CLAMP1
- **床は空いたが、脚の周りのホコリを取る道具がない** → マキタ CL108FDSHW

この記事でいちばん言いたいのは、順番のほうです。掃除機を買い替える前に、床に触れている物を6個減らす。効果の大きさが違いますし、費用も1/3で済みます。

冬になると、この0.72m²にパネルヒーターを置きたくなる人も多いと思います。床に物が1つ増える話でもあるので、足元を温める道具を何Wで選ぶかは<a href="/blog/wanroom-ashimoto-heater-aircon-kansan/">足元ヒーターをエアコンの設定温度に換算した記事</a>にまとめました。

	<p class="q">Q. トレーに電源タップを載せると熱がこもりませんか？</p>
	<p>A. ワイヤーやメッシュのトレーは底が開いているので、床置きやプラスチックのケーブルボックスに入れるより通気は取れます。むしろ注意すべきはタップに挿す合計ワット数のほうで、こちらは接地点の話とは別問題です。電源の分け方は<a href="/blog/wanroom-consent-tarinai-dengen-tap/">「コンセントが足りない」の記事</a>で詳しく書いています。</p>
</div>
<div class="faq-item">
	<p class="q">Q. 2,000円くらいの安いハンディクリーナーではだめですか？</p>
	<p>A. 選択肢としてはありますが、編集部が調べた範囲では評価が伸びていない製品が多い印象でした。たとえば山善 ZHF-N36は隙間ノズル付きで2,000円台ですが、242件で★3.0、充電8時間に対して連続使用10分という仕様です。机の上の消しカスや髪の毛用と割り切れるなら選べますが、床のホコリを相手にする道具としては力不足だと考え、この記事では推奨リンクを置いていません。</p>
</div>
<div class="faq-item">
	<p class="q">Q. ロボット掃除機を買えばデスク下も解決しますか？</p>
	<p>A. しません。デスク下は高さでは引っかからないのに、脚とキャスターとケーブルでロボットが進入できない区画です。しかもロボットは入れなかった面積をアプリ上で報告しないため、掃除されていないこと自体に気づけません。デスク下は人がやる前提で計画してください。</p>
</div>
