## Web会議は、あなたが思っているより帯域を使っていない

最初に数字を置きます。ここを共有しないと、この先の話がぜんぶ「気休め」に見えてしまうので。

Zoomが公開している推奨帯域は、グループ会議で1080p送信のときに<strong>上り3.8Mbps・下り3.0Mbps</strong>、720pなら上り2.6Mbps・下り1.8Mbps程度です。1対1ならもっと少ない。プランや設定で前後しますが、桁としてはこのくらいで、要するに<strong>数Mbpsの世界</strong>です。

| 用途 | 必要な帯域の目安 |
| --- | --- |
| Web会議（720p・グループ） | 上り2.6Mbps前後 |
| Web会議（1080p・グループ） | 上り3.8Mbps前後 |
| 動画配信サービスの4K視聴 | 下り25Mbps前後 |
| 速度テストで「遅い」と感じ始める線 | 30Mbps以下 |

速度テストが80Mbpsを返している回線に対して、会議が求めているのは<strong>その数パーセント</strong>です。だから「回線が遅いから会議が止まる」という説明は、多くの家庭で成立していません。

では何が起きているのか。会議アプリが嫌うのは太さではなく<strong>途切れ</strong>です。一瞬の切断、遅延のばらつき（ジッタ）、届かないパケット。速度テストは10秒前後の平均を出す道具なので、<strong>1秒の断絶はほぼ計測に出ません</strong>。平均は満点、体感は最悪、という食い違いはここから来ます。

そして、ワンルームで途切れを起こしている犯人には、わりとはっきりした候補が2つあります。

## 犯人1：ルーターが箱の中にいる

賃貸のワンルームでは、光回線の引き込み口とルーターの置き場所が、住人の意思とほぼ無関係に決まっています。玄関脇の情報分電盤（マルチメディアコンセント）の中、あるいは下駄箱の最上段。扉つきの収納の中に、ONUとルーターがまとめて押し込まれている物件は本当に多い。

<strong>Wi-Fiの電波は、扉一枚でしっかり弱まります。</strong>金属の分電盤の中なら、なおさらです。部屋が20㎡しかないから距離は近いはずだ、という直感は正しいのですが、直線距離5mの見通しと、直線距離5m＋扉＋金属箱ではまったく別物になります。

ここで効いてくるのがもう一つのワンルーム特有の事情で、<strong>机とキッチンが数メートルしか離れていない</strong>ことです。電子レンジは2.4GHz帯に強いノイズを出します。会議中に温め直しをすると、2.4GHzでつないでいる端末は素直に影響を受ける。「昼の会議だけ調子が悪い」という人は、一度この線を疑ってみる価値があります。

## 犯人2：5GHzが、法律に従って60秒黙る

こちらは知られていない割に、症状がやたら特徴的です。

日本の5GHz帯は3つのブロックに分かれていて、W52（36/40/44/48ch）、W53、W56があります。このうち<strong>W53とW56は気象レーダーや航空レーダーと周波数を共用している</strong>ため、電波法上、ルーターはレーダー波を検知したらそのチャンネルを明け渡す義務があります。これがDFS（動的周波数選択）です。

具体的な挙動はこうです。使用開始前に60秒間スキャンし、動作中にレーダー波を検知したら別チャンネルへ移動、<strong>元のチャンネルは30分間使用禁止</strong>。移動先で改めて60秒スキャンするので、その間は通信が止まります。

つまり、<strong>「何の前触れもなく1分ほど落ちて、勝手に復活する」</strong>という症状が出たら、それは故障でも回線の問題でもなく、ルーターが仕様どおりに動いた結果かもしれません。空港や気象レーダーの近く、高台の物件では起こりやすいと言われています。

対策は設定変更だけで済みます。ルーターの管理画面で5GHzのチャンネルを<strong>W52（36/40/44/48のいずれか）に固定する</strong>。W52は屋内限定でレーダーとの共用がないため、DFSによる停波が起きません。0円です。

正直に書くと、<strong>これが自分の環境で当たりかどうかを事前に見分ける方法は、編集部にはありません。</strong>ログを追える機種なら記録が残りますが、家庭用ルーターでは出さないものも多い。ただ設定を変えるコストがゼロなので、症状が合うなら試す価値は高いと考えています。

## 買う前に、0円で試すこと

順番はこれです。上から順にやって、直ったらそこで止めてください。

1. <strong>ルーターを箱から出す。</strong>扉を開けておくだけでも変わります。分電盤の外に出せるなら、床から少し高い位置、金属と水回りから離れた場所へ。
2. <strong>接続先のSSIDを5GHz側に固定する。</strong>「〜-G」と「〜-A」の2つが見えているなら、Aのほう（5GHz）です。2.4GHzは遠くまで届く代わりに、集合住宅では隣近所と混み合い、電子レンジとも重なります。
3. <strong>5GHzのチャンネルをW52に固定する。</strong>上のDFSの話です。
4. <strong>机の近くの壁に、LANの差込口がないか探す。</strong>意外と見落とされます。テレビ端子の隣に情報コンセントが来ている物件があり、そこが生きていればルーターごと机の近くに移せます。

ここまでで直らなかった人のための話を、以下に書きます。

## 結局いちばん効くのは、1,000円ちょっとのLANケーブル

身も蓋もない結論ですが、<strong>Web会議の安定を金で買うなら、有線化のコストパフォーマンスは他のどの選択肢にも勝ちます。</strong>

理由は単純で、これまで挙げてきた原因のほぼ全部が消えるからです。扉も、電子レンジも、隣室のWi-Fiも、DFSも、有線には関係がありません。数千円のルーターを買い替えて改善を祈るより、1本のケーブルのほうが確実です。

「ワンルームを横断するケーブルなんて無理だ」と思うかもしれません。ここについては後の節で書きますが、<strong>フラットケーブルはドアの下も幅木沿いも通せます</strong>し、電源コードと違ってLANケーブルは電力を運ばないので、踏まれても発熱しません。<a href="/blog/wanroom-consent-tarinai-dengen-tap/">電源まわりを整理した記事</a>で「延長コードをラグの下に通すな」と書きましたが、その理屈はLANケーブルには当てはまりません。ここは扱いを分けて考えて大丈夫です。

そのうえで、条件が合う人には良い製品です。Deco X50/AはAX3000（2402＋574Mbps）で、1ユニットにつきギガビット有線ポート3つ。レビューは4.5・1,501件と、この価格帯としては評価も母数も良好です。設定はアプリ主導で数分、メーカー保証3年、Matter対応。

<strong>買う価値があるのは、「ワンルームではない」かつ「部屋をまたいだ先で会議をしている」人だけ</strong>だと考えています。実家に戻って働くことになった、1LDKの奥の部屋を仕事場にした、といったケースです。逆にその条件に当てはまるなら、中継機で粘るよりメッシュに行くほうが結果的に安上がりになることが多いはずです。

## 今回すすめなかった手

<strong>Wi-Fi中継機。</strong>3,000〜4,000円で買えるので最初の候補に挙がりやすいのですが、ワンルームでは勧めません。多くの中継機は親機からの受信と端末への送信を同じ電波で行うため、原理的に実効速度が落ちます。加えて、端末が「弱いけど掴んでいる」親機に居座って中継機に切り替わらない、という挙動もよくある。<strong>元の電波が弱い場所に置けば弱いまま中継し、強い場所に置けば意味がない</strong>——設置場所がシビアな道具で、20㎡の部屋にその難しさを持ち込む理由が薄いと考えています。

<strong>PLCアダプター（コンセントでLANを飛ばす）。</strong>発想としては賃貸に向いています。壁に穴を開けず、電源のある場所ならどこでもLANになる。ただ現行で入手しやすい製品が10年以上前の世代のものに寄っていて、速度も安定性も現代のWi-Fi 6に対して優位とは言い難い。ブレーカーをまたぐと繋がらない、他の家電のノイズを拾うといった条件もあります。<strong>ケーブルが引けるなら、迷わずケーブルです。</strong>

<strong>回線そのものの乗り換え。</strong>速度テストで80Mbps出ている人がやることではありません。工事と契約期間と初期費用が発生する話なので、上に書いた0円の切り分けを全部やってからでも遅くない。夜間だけ極端に落ちる（10Mbpsを割る）ようなら、そのときは検討する価値があります。

<strong>Wi-Fi 7ルーター。</strong>2026年時点で選択肢は増えましたが、Web会議の途切れを直す目的では完全に過剰です。数Mbpsを安定させたいだけの用途に、規格の最上位を買う必要はありません。

## よくある質問

<div class="faq-item">
	<p class="q">Q. 速度テストで80Mbps出ているのに会議が固まるのはなぜですか？</p>
	<p>A. 速度テストは10秒前後の平均値を出す道具で、1秒程度の切断はほとんど数値に現れないためです。Web会議が必要とする帯域はグループ会議の1080p送信でも上り3.8Mbps前後と小さく、80Mbpsの回線に対して数パーセントしか使っていません。困っているのは太さではなく、途切れ・遅延のばらつき（ジッタ）・パケットロスのほうです。</p>
</div>
<div class="faq-item">
	<p class="q">Q. Wi-Fiが1分ほど突然切れて、勝手に復活します。故障ですか？</p>
	<p>A. 5GHzのW53/W56チャンネルを使っている場合、DFS（動的周波数選択）による正常な動作の可能性があります。これらのチャンネルは気象レーダーや航空レーダーと周波数を共用しており、レーダー波を検知するとルーターはチャンネルを移動し、移動先で60秒のスキャンを行います。その間は通信できません。ルーターの管理画面で5GHzのチャンネルをW52（36/40/44/48）に固定すると回避できます。</p>
</div>
<div class="faq-item">
	<p class="q">Q. LANケーブルをカーペットやラグの下に通しても大丈夫ですか？</p>
	<p>A. 電源の延長コードとは事情が違い、LANケーブルは電力を運ばないので発熱の心配はありません。エレコム自身も、厚さ1.4mmのフラットケーブルについて「カーペットの下やドアのすき間に配線できる」と説明しています。注意すべきなのは発熱ではなく物理的な断線で、椅子のキャスターが同じ一点を繰り返し踏む場所だけは、カバーで保護するか経路を変えてください。</p>
</div>
<div class="faq-item">
	<p class="q">Q. 中継機とメッシュWi-Fiはどちらを買うべきですか？</p>
	<p>A. ワンルームであれば、どちらも買わないのが最善だと考えています。20㎡程度の部屋で電波が弱い原因は距離ではなく、扉つき収納の中にルーターがあることや2.4GHz帯の混雑であることが多く、機器を足しても解決しません。部屋をまたぐ距離が実際にあるならメッシュのほうが安定します。中継機は設置場所の条件が厳しく、実効速度も落ちやすいため、優先度は下がります。</p>
</div>
<div class="faq-item">
	<p class="q">Q. ノートPCにLANポートがない場合、有線化はあきらめるべきですか？</p>
	<p>A. USB-Cから変換するアダプタが1,500円前後で買えるので、あきらめる必要はありません。Windows 10/11・macOS・ChromeOSならドライバのインストールも不要です。ひとつだけ注意点があり、給電専用のUSB-Cポートでは動作しません。認識しない場合はデータ通信に対応した別のポートを試してください。</p>
</div>
